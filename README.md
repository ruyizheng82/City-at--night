
# City at Night

This is my Creative Coding project made in Processing Java Mode.

I wanted to create a simple nighttime city and gradually make it feel more alive through animation. The scene started with a dark blue sky, buildings, a moon, windows and a road.

I later added a moving car, changing window lights, twinkling stars, moving clouds and streetlights. I also added a traffic light so the car can stop and move depending on the signal.

## How to Run

1. Download Processing from https://processing.org/
2. Open Processing in Java Mode.
3. Open the project code in Processing, or copy the code into a new sketch.
4. Click Run to see the animation.

The canvas size is 800 x 600 pixels.

## Code Used

I used basic Processing functions such as `rect()`, `ellipse()` and `fill()` to draw the city.

I also used:
- `for` loops to create building windows and road markings.
- `frameCount` to change the window lights and traffic signal.
- Variables to move the car and clouds.
- `if` and `else` statements to control the car.
- `sin()` to make the stars twinkle.
